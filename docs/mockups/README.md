## Come usarli
- Sono file di testo in un formato di tela di progettazione: aprili con un editor o falli leggere a Claude. Non si aprono direttamente nel browser, perché mancano dello script di supporto.
- Gli stili sono inline e contengono i valori da riprendere. Riferimenti ricorrenti: primario `#0B6E6A`, primario chiaro `#E3F1F0`, primario scuro `#0B4F4C`, sfondo `#F3F5F7`, superfici `#FFFFFF`, bordo `#DDE3E8`, testo `#14212B`, testo attenuato `#55646F`, negativo `#B23A0A`. Font: IBM Plex Sans per il testo, IBM Plex Mono per le cifre.
- I **dati sono illustrativi**: cifre e movimenti vengono dall'export e dal foglio 2026, ma non vanno trattati come dati veri. Nella home i saldi per conto sono segnaposto `[saldo]`.
- I mockup non sono stati verificati visivamente a schermo: in caso di dubbio sul layout decide l'autore.
